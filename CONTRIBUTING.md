# Contributing

This is a personal portfolio project showcasing Kubernetes and DevOps practices.

## For Learning/Reference

Feel free to:
- Fork and learn from the setup
- Use configurations as templates
- Reference in your own projects
- Ask questions via issues

## For Production Use

Before using in production:
- Customize for your environment
- Review security configurations
- Test thoroughly in staging
- Adapt resource limits to your hardware

## Issues & Discussions

Report issues or share improvements via GitHub issues.

Thanks for your interest!
